RyzeMP beta.4 makes the Bedrock 1.26.60 / protocol 2225 integration available through the normal PHAR and Composer distribution.

- Locks the published BedrockProtocol and BedrockData 1.0.0-beta.2 packages. No CI-only protocol patch, path repository or development-branch override is required.
- Uses first-party RyzeRTC v0.1.0-dev.3 / API 2 for authenticated NetherNet on the existing server-ip/server-port, with HTTP TCP and RakNet/WebRTC UDP sharing the public allocation. The native module stays outside the PHAR.
- Includes official JWKS/JWT validation, signed DTLS-bound SDP, native ICE/DTLS/SCTP and Minecraft DataChannel sessions, pending-session limits and cleanup, and persistent server signing identity.
- Fixes the reproduced chorus-plant creative-inventory failure after login and selects the paired 1.26.60 item tags.
- Publishes ryzemp-update.json so the updated Pterodactyl egg can install this release and its matching runtime when Reinstall is pressed. Default channel: pruebas. Worlds, plugins, configuration and operator key are preserved, with a previous-software backup.
- Preserves PocketMine-MP 5 plugin namespaces/API, existing multiversion codecs and legacy RakNet. The PHAR excludes native libraries and test plugins.

Validation: complete PHP regression suite; protocol regression (829 tests); paired versioned data checks; cryptographic identity and signed SDP rejection tests; actual native shared-port binary ICE/DTLS/SCTP exchange including concurrent peers and reconnect; real PHAR HTTP/RakNet startup, persistent identity and restart; synthetic pre-spawn, creative/crafting packets, terrain and world spawn; public plugin API fixture with 42 commands across legacy and current protocols. Release logs and checksums are attached.

The operator already confirmed retail-client login and world entry with integration.2, which contains the same transport and world-entry fixes. Beta.4 still needs the operator's final real-panel Reinstall and gameplay/disconnect/reconnect checks. It is a prerelease; automated tests do not certify every retail gameplay path. The optional private HCF integration requires a separately authorized read token and is not claimed as validated by this release. HardCoreFactions source is unchanged. No Amber code or dependency.

Developers: composer create-project ryzemcbe/ryzemp ryzemp "1.0.0-beta.4" --no-dev --prefer-dist

Operators: update the official egg once, select RYZEMP_CHANNEL=pruebas, then Reinstall. SHA-256 checks and matching native-runtime installation are automatic. Direct installations require a compatible PHP 8.4 ZTS environment and RyzeRTC outside the PHAR.
