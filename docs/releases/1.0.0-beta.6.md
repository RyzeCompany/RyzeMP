# RyzeMP 1.0.0-beta.6 — VanillaMine multiversion base

This is a **beta** release for Minecraft Bedrock clients. It replaces the previous legacy RyzeMP core with the VanillaMine-based multiversion integration and preserves RyzeMP identity and PocketMine-MP plugin API 5.44.2.

## Main changes

- VanillaMine gameplay, worldgen, structures, entities, vanilla items, mobs and natural spawning, with Bedrock multiversion routing retained.
- Bedrock 1.26.60 via **RyzeRTC API 2** as the only NetherNet transport. RakNet and RyzeRTC share one public UDP port; HTTPS signaling works on the same public TCP port with configured PEM certificates. Native RyzeRTC stays outside the PHAR.
- Worldgen acceleration from [RyzeVanillaGen v0.1.0](https://github.com/RyzeCompany/RyzeVanillaGen/releases/tag/v0.1.0), protocol 7 / algorithm 4, installed by the [official Egg](https://github.com/RyzeCompany/egg-ryzemp). No Go executable inside the PHAR; PHP worldgen remains a fallback.
- Existing pocketmine.yml is not overwritten: missing options have runtime defaults; obsolete fishing timing/pull and level minimum Y settings warn at startup. Legacy fishing enabled, pvp-enabled and max-distance settings remain supported.
- Automatic crash reporting and unrelated VanillaMine/PocketMine update checking disabled by default. Official updates come from RyzeCompany releases and the Egg.
- Software version 1.0.0-beta.6 is separate from PocketMine-MP plugin API 5.44.2.

## Upgrade

Back up worlds, plugins, pocketmine.yml, server.properties and NetherNet identity files. Import the validated Egg, select RYZEMP_CHANNEL=pruebas, then use Reinstall to fetch the immutable PHAR and external native dependencies. The Egg preserves server data and a rollback backup.

Read the [pocketmine.yml upgrade guide](https://github.com/RyzeCompany/RyzeMP/blob/main/docs/POCKETMINE_YML_UPGRADE.md) before changing performance, mobs, dimensions or world settings. Old installations retain compression level 6 and async worker memory 256 MiB until explicitly changed.

## Release verification

Publication requires **both** the full integration CI and extended native/data CI green on the exact merged main commit. The PHAR has a SHA-256 digest. The ryzemp-update.json manifest is uploaded last in schema 1, supported by old and new Eggs. Go binaries and RyzeRTC native libraries are not shipped in the PHAR or RyzeMP release.

Bedrock 1.26.60 joining successfully is encouraging, but this beta should also be trialed with 1.26.40 (RakNet), mixed sessions, inventories, existing LevelDB worlds, saves, restarts, reconnects and realistic load. **Not a production-stable certification.**
