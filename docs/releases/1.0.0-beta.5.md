RyzeMP beta.5 is a temporary diagnostic release for the unresolved Bedrock command autocomplete issue in HardCoreFactions.

- Adds automatic, one-time-per-connection `[CrateCommandTrace]` INFO records for `/crate edit` and `/crate remove`, without configuration changes.
- Compares plugin-generated command metadata (`stage=metadata`) with the final outgoing `AvailableCommandsPacket` after serialization and the packet-send event (`stage=wire`). It records protocol ID, overloads, argument types, enum names and enum values, but no raw packets, IP addresses or player-typed chat.
- Includes earlier multi-version command enum normalization and canonical command permission encoding.
- Fixes a login-blocking `ErrorException` in the temporary crate trace when a `/crate` overload has no arguments. Metadata/wire diagnostics now tolerate empty overloads and isolate trace failures so they cannot interrupt NetherNet pre-spawn command synchronization.
- Adds regression coverage for no-argument `/crate`, metadata serialization and command synchronization with 589, 649, 898, 2193 and 2225, without changing the command API or user-facing crate behavior.
- Preserves the same Bedrock 1.26.60 / protocol 2225 compatibility, existing PHP/runtime requirements, RyzeRTC native API 2, PocketMine-compatible plugin API, worlds, plugins and configurations as beta.4.
- Does not claim that the `default` autocomplete bug is fixed. The operator must provide the `[CrateCommandTrace]` lines from a real login for root-cause diagnosis. This logging is temporary and intended to be removed in a later release.

For the Pterodactyl egg, select the `pruebas` update channel and click **Reinstall** after the release is published. The installer checks the official `ryzemp-update.json` manifest, verifies SHA-256 checksums and preserves server data. A normal restart does not install a new PHAR.

Validation: PHP regression suite, Bedrock 2225 cross-repository integration, PHAR build plus real startup and public command API smoke tests. These tests do not replace a real Minecraft client's visual autocomplete verification.
