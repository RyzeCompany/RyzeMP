# 5.45.0
Released 17th October 2026.

This is the first release of **VanillaMine**, the VanillaPocketMine fork of PocketMine-MP (pmmp archived the original project in July 2026). It supports Minecraft: Bedrock Edition 1.26.52 (display version 26.52, protocol 2193).

**Plugin compatibility:** Plugins for previous 5.x versions will run unchanged on this release, unless they use internal APIs, reflection, or packages like the `pocketmine\network\mcpe` or `pocketmine\data` namespace. The plugin API only gained additions.
Do not update plugin minimum API versions unless you need new features added in this release.

**WARNING: If your plugin uses the `pocketmine\network\mcpe` namespace, you're not shielded by API change constraints.**
Consider using the `mcpe-protocol` directive in `plugin.yml` as a constraint if you're using packets directly.

**PHP binaries:** use the PHP 8.4 binaries of [VanillaPocketMine/PHP-Binaries](https://gitlab.com/VanillaPocketMine/PHP-Binaries/-/releases) (chunkutils2 0.3.9). The server also runs with older binaries, without the native speed-ups.

## General
- Added support for Minecraft: Bedrock Edition 1.26.52; removed support for earlier versions. Block network IDs are now hashed.
- Added the NetherNet (WebRTC) transport used by Bedrock 1.26.50+ clients, on the same port as RakNet (TCP signaling, UDP data), with optional HTTPS and automatic certificates.
- Server messages are translated to each player's own language.
- The auto-updater now uses `updates.luxurynodes.com`.
- RakLib anti-spoofing cookies are available (`network.raklib-anti-spoofing-cookies`, off by default).
- A plugin failure while handling a NetherNet packet only disconnects that player, like on RakNet.

## Gameplay
- New `vanilla` world generator: vanilla Overworld, Nether and End terrain, caves, decoration and structures, with a native terrain core (Go) shipped in the phar. The old generators are unchanged.
- Mobs: AI, pathfinding and Bedrock-like spawning for the vanilla mobs, including villagers (professions, trading, beds, doors, zombification and cure), raids, piglins, the bosses (Ender Dragon with respawning, Wither), creaking, golems, riding and horse inventories, at vanilla speeds.
- Weather with lightning, redstone (phase 1), pistons, sensors, minecarts, boats, bundles, maps, beacons, enchanting, fishing, anvils, looms, leads, sculk, conduits and many more vanilla blocks and items; the creative inventory matches vanilla.
- Fixes to scaffolding, maces, eating, shulker boxes and happy ghasts, among others.

## Commands
- Commands send their real syntax to the client, so the chat shows Bedrock's own suggestions (item and block names, players, enums), including for plugin commands that declare overloads.

## Networking with VanillaGate
- Added `network.proxy` in `pocketmine.yml`: servers can sit behind [VanillaGate](https://gitlab.com/VanillaPocketMine/VanillaGate) (the proxy, called pm-proxy during development), which checks Xbox Live logins once and moves players between servers without reconnecting (`/server`, `/hub`, fallback when a server stops).
- API: `Server::getProxyNetwork()`, `Player::transfer()` through the proxy, `PlayerProxyTransferEvent`, `ProxyMessageReceiveEvent`.

## Performance
- Simulation distance is 4 chunks by default, and chunk loading, entity ticking, world changes and the network fan-out were reworked for servers with many players; with chunkutils2 0.3.9 chunk serialization, random ticks, pathfinding and timings run natively.
- `network.compression-thread` compresses the packet batches in a dedicated thread. It is off by default: with it on, players noticed a delay on their actions.
